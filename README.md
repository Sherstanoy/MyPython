## Как запустить?
1. Требуется установить Python
2. - Нажмите зеленую кнопку `<> Code` → `Download ZIP`.
   - Распакуйте архив. Допустим, вы сохранили его на Рабочий стол в папку `MyPython`.
3. Запустите программу через полный путь:

Откройте терминал (PowerShell) и введите команду ниже.

Важно: Замените `user` на имя вашего пользователя Windows!

```bash
python "C:\Users\user\Desktop\MyPython\test.py"

Или, если файл лежит в Загрузках:

```bash
python "C:\Users\user\Downloads\MyPython\test.py"
